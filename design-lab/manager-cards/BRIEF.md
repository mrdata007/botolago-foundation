# BotolaGO Manager Card — visual exploration

## Preserve

Production routes, navigation, profiles, fantasy rules, scoring, services, schema and release configuration remain untouched. This is a separate local HTML design lab, outside `src/` and `public/`, with no API calls or production import. All ten cards use the supplied fictional ALI profile, PRO / 84 OVR and identical stats. No XP, monetization or progression formula.

## Inspected foundations

Read PRODUCT.md, DESIGN_SYSTEM_V2.md, src/styles.css, src/fonts.css, Logo.tsx, profile.tsx, fantasy.rankings.tsx, MyRankCard.tsx and the separate demo architecture. The current system uses deep BotolaGO blue (oklch 0.32 0.1 258), cyan accents, Changa display/standalone scores, Manrope body/tabular numbers, Noto Sans Arabic, a 4px spacing scale, 14px cards, 16px feature surfaces and pill controls. White wordmarks endorse dark surfaces. Profile groups are restrained rows; rankings favor tabular scanning over decorative podiums. Both light and dark themes and French/Arabic matter.

## Specific exploration

Ten independent compositions: Street, Stadium Pass, Future Botola, Terrace, Broadcast, Minimal Luxury, Digital Passport, Arcade, Stadium Architecture and an original Touchline wildcard. Silhouette, number placement, avatar framing, materials, founder mark and stat layout change across concepts. Keep existing fonts and authentic logos. Experimental materials/silhouettes are intentionally local to this lab, as the owner's brief requests; no shared design tokens change.

## Acceptance criteria

- Ten rendered cards in a comparison gallery plus an overview/contact sheet.
- Keyboard-accessible close-up dialog, previous/next navigation and readable rationale for every concept.
- ALI; 84 OVR; PRO; Morocco; generic club crest; 2026/27; BOT #004821; FOUNDER 2026; CAP 91 / SEL 82 / TRF 86 / CON 78 on every full card.
- Shared neutral avatar with replaceable photo/illustration/anonymous presentation; appearance does not depend on a photo.
- Compact leaderboard identity for each concept; documented HOMA → STADE → PRO → CHAMPION → LEGEND material progression, without implementing tiers.
- Design idea, emotional connection, ownability, progression and risk for each, plus ranked recommendation using the owner's priorities.
- Desktop and mobile screenshots, French and Arabic/RTL checks, light/dark surround, no layout collisions or unexpected horizontal overflow, reduced-motion support and 44px controls.
- Standalone downloadable HTML and PNG comparison/close-ups. No deployment. Draft review branch only.
