# Selection progression while native ratings are pending

Owner authorization: 20 October 2026, “go”, following the verified GW6 opening risk. Objective: make the next selection window available after the preceding counted matches genuinely finish, without inventing points, shortening the approved Not rated evidence period, changing prices/transfer rules or bypassing finalization integrity.

Primary evidence: live production lifecycle functions inspected on 20 October. Native ratings explicitly disable the older staged-statistics policy. Scoring preparation requires a valid native document; a partially rated document may produce an unsealed snapshot, but the worker then waits before its close steps. The close must therefore be an independent administrative operation before scoring preparation, not a relaxation of the complete-scoring close guard.

Implementation contract: a service-only, version-checked selection-close RPC requires an active native-rating season, a provisional gameweek, locked historical lineups and valid frozen counting assignments whose fixtures are genuinely finished. It records a distinctly typed administrative close and uses the existing resumable Free Hit, free-transfer, transfer-demand price and next-gameweek preparation journals. It writes no scores, ratings, snapshots, prizes or points-ready events. Existing finalization guards remain unchanged. Finalization later adopts the completed price pass and never repeats it.

Native close versions are administrative journal versions, not published scoring versions. A close must not change `scoring_input_version` or synthesize a scoring snapshot. Its digest identifies the exact native document observed at close. The worker resumes incomplete carry-over before attempting further scoring. Missing ratings return a normal waiting result; real ratings may finalize through the existing scorer and exact-version notification gates.

Validation: database tests must prove opening with genuine pending-rating evidence; refusal of unauthorized calls, unended fixtures, unresolved assignments, unlocked lineups and stale versions; unchanged points/ratings and finalization refusal; retry-safe interrupted price/transfer batches; later rating settlement and finalization with no repeated economic changes or edits to successor selections. Worker tests cover both pending and ready ratings, resumptions and the unchanged older staged path. Independent production fingerprints protect all existing selections, results, native evidence and notification records during release. GW5 is currently open, so release must not close it or open GW6 early.

Workflow: new forward migration; targeted local tests and authoritative database CI; staging real-path rollback rehearsal and independent verification; guarded production release with related writers paused/drained; identical-source apply, original switch restoration, source-pinned worker deployment and normal health/owner-read verification. No production time manipulation or synthetic test data.
