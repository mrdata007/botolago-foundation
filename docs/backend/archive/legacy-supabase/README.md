# BotolaGO Legacy Supabase — Do Not Deploy

This directory is an archive-only snapshot of the abandoned Supabase work that
previously lived under `supabase/`.

- It is not canonical.
- Its migrations must never be replayed into BotolaGO Production V2.
- Its generated types, table names, policies, and RPC contracts are behavioral
  references only.
- Historical data migration, if ever approved, must use a separately reviewed
  export/transform/import plan rather than these migrations.

The active greenfield configuration and migration chain live at the repository
root under `supabase/`.
