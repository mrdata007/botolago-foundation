# Screen coverage report (subtext overhaul, before the change)

> Screenshots named here were kept in the audit workspace, outside the repository. They were captured on the sample-data build (mock sign-in) before any copy change. `screens/` next to this file holds the before and after pairs for the most improved screens.

Run: 2026-10-16, dev server http://127.0.0.1:4173 (mock auth + mock data; read-only on the repo). Screenshots: `<audit workspace>/shots/agent1/` (`S=<audit workspace>`).

**Out of scope (listed, not shot):** `admin.*` (14 routes), `dev.*` (8 sample routes), `[.]well-known/oauth-protected-resource`, `[.mcp]/*`, `mcp.ts`, `sitemap[.]xml`, `[.]lovable.oauth.consent` (OAuth consent: source only), legal text (`/privacy`, `/terms`, `/prizes/terms` were shot but their body is out of scope).

**Coverage numbers.** 68 route addresses x 4 variants (FR/AR x mobile 390@2x / desktop 1366) shot anonymously = 272 PNG; 32 signed-in routes x 4 variants = 128; 65 tab/dialog/sheet/error states FR+AR mobile = 130; plus flow shots (transfers flow, auth prompt, share sheets, search, empty day), first-launch (splash, language chooser, landing), registration flow (FR) and extras (Curva `?mc=` fixtures, BotolaGO+ `?plus=` scenarios). Every captured page printed real text (no blank/spinner/error); no horizontal overflow (`scrollWidth>clientWidth`) and no page errors on any captured route (manifests in `shots/agent1/manifests/` and `_manifest-*.json`). I looked at contact sheets (`shots/agent1/sheets/*.png`) of all FR mobile anon, FR mobile signed-in, AR mobile anon (all) and AR signed-in (most), FR states, flows, plus several desktop ones; the other variants were checked by manifest (title/dir/overflow/text) only, not eyeballed. Desktop = same mobile column centred in a 1366 viewport (Home and /plus use 2 columns).

**Key facts for the other agents** 0. In mock mode, signed-out Fantasy screens show the demo squad (local data source), so real signed-out gates are not visible (see issue notes).

1. The demo account already has a Fantasy squad, Curva card, 4 leagues, so `/fantasy/create` (empty squad builder, team-name step, captain choice) is **not reachable** in mock (redirects to `/fantasy/team`).
2. Prospects (`/pepites`), Curva, BotolaGO+, Pronostics and News are all ON in this dev build (feature flags true).
3. `<title>` / meta description are French-only on ~30 routes in Arabic (see C1 row 3).
4. Dictionary: 3258 keys; ~247 unused (W3), 4 orphan components, one hard-coded FR-only string in a user path (`saved-articles.ts`).
