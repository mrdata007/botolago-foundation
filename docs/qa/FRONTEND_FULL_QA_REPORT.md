## Automated harness

The Playwright configuration provides:

- anonymous, guest, deterministic authenticated, and opt-in live-auth fixtures;
- `mobile-fr` (390x844), `desktop-fr` (1440x900), `mobile-ar` (390x844), and `desktop-ar` (1440x900) projects;
- local and `E2E_BASE_URL` targets;
- screenshots and traces on failure, an HTML report, sanitized console/page-error capture, failed-request and HTTP 4xx/5xx detection;
- checks for a visible/non-empty document, framework error overlays, broken visible images, horizontal overflow, and clipped interactive controls;
- explicit opt-in commands for public local, deployed, and authenticated verification.

4. Paste the real registration verification/reset link when ready. The final real reset password submission remains user-controlled.
5. Use only temporary live account artifacts for cloud squad/league testing; do not mutate pre-existing account data.
