# Gradins (the Manager Card section): evidence index

Every acceptance criterion of plan section 9, how it was measured, what it gave, and the file that holds it.
The plan is [`../MANAGER_CARD_SECTION_PLAN.md`](../MANAGER_CARD_SECTION_PLAN.md), the screen-work brief
[`../MANAGER_CARD_SECTION_BRIEF.md`](../MANAGER_CARD_SECTION_BRIEF.md) (copied into the pull request description).
Everything below was measured on the merged section branch after the finish review's fixes: source at
`d3d5b56e` (the last source commit), plus the commits that add the browser specs and this folder. Nothing here
touched a database, a migration, an Edge Function, a deployment or Lovable: every run used the mock data modes
(`VITE_*_DATA_MODE=mock`, `VITE_AUTH_MODE=mock`) or the production build against the e2e stub backend.

Measured as CLAUDE.md "Evidence" asks: overflow from element rectangles (never `scrollWidth`, which
`html, body { overflow-x: clip }` hides), contrast from rasterised pixels, each run against a server started from
the tree being measured on its own port (4186 for this branch, 4181 for the base tree). Where a check could not
run, or ran and did not give what the plan wants, it says so in the row.

card of a dark club) is unchanged. Measured from rasterised pixels at three pixels per CSS pixel (`wp6b/dash-contrast.mjs`, `dash-contrast.py`),

The brief asked for a mid-tone **and** at least 3:1 against the rib. On a pale rib the two cannot both hold: 3:1 against a rib of about 0.25
relative luminance (its darker column) needs a dash darker than about 0.05, whatever its hue, and a true mid-tone is about 2:1. The build keeps
the 3:1 floor, so the change is a warm shade in place of a neutral charcoal and the bar still reads dark. If the owner wants it to read lighter,
the way is not a lighter colour but a lighter shape (a thinner or tapered dash) or a rib without dark columns behind it: an owner decision, below.
I tried knitting the dash in the rib's own columns; it changed almost nothing to the eye and made the cream dash on a dark club worse (2.68:1
to 1.94:1 against its lighter column), so it was removed.
