# Screen coverage

98 implemented route definitions inventoried. These include index/layout definitions, redirects, development fixtures and staff screens; they are not 98 distinct public workflows. 435 accepted baseline captures cover 322 named-state/language/viewport combinations. Repeated captures are not additional screens.

All application captures use development mock data and synthetic browser-local sessions. No production account, content, payment, entitlement or database write was performed. Valid screenshots prove the named rendered state only; a staff error page or sign-in redirect does not verify the protected workflow.

## Inspection levels

- **Full image inspected:** the specialist opened that screenshot; this does not assert every pixel or interaction was checked.
- **Contact sheet inspected:** only the named top-of-screen crop was viewed. Long-page body text and lower controls are not visually validated by that thumbnail.
- **Captured only:** rendered raster and exact language/direction metadata exist, but no individual image inspection is claimed.
- **Source only:** implementation inventoried; the underlying screen/state has no rendered evidence.
- Rejected first-paint locale frames, loading/overlay mistakes, interrupted captures and harness failures are retained as diagnostics in JSON, excluded from accepted evidence.

The visual/design and localization specialists separately inspected full priority-screen images. Their fresh after-comparisons and the independent reviewer’s accepted views are documented in [VISUAL-COMPARISONS.md](VISUAL-COMPARISONS.md) and [INDEPENDENT-REVIEW.md](INDEPENDENT-REVIEW.md).
